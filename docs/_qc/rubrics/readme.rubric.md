# README rubric (base + extensions)

Inherits the four base dimensions from base.rubric.md. Pass floor 7.

## Dimension 5: Product Framing First
- 9-10: The opening paragraph reads as Working-Backwards PR-FAQ style: what the product does for the user, before how to install it.
- 7-8: Product framing leads; setup follows.
- 4-6: Mixed; setup competes with product framing for the first screen.
- 0-3: Reads as a setup guide with product framing tucked at the bottom.

## Dimension 6: Setup Demoted
- 9-10: Setup section is reachable but not the lede. Below at least one substantive product section.
- 7-8: Setup demoted but appears in the first half.
- 4-6: Setup is the second section.
- 0-3: Setup is the first thing the reader sees.

## Dimension 7: Lineage Disclosure Preserved
- 9-10: The intelliflow-core lineage is disclosed clearly without subordinating BrandGuard ("upstream governance kernel"; not "module of").
- 7-8: Lineage disclosed; phrasing acceptable.
- 4-6: Lineage disclosed weakly.
- 0-3: Lineage missing or BrandGuard subordinated to IntelliFlow OS.
